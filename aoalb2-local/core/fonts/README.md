# 同梱フォント

| ファイル | 書体 | 版 | 著作権者 | ライセンス | 入手元 |
|---|---|---|---|---|---|
| BIZUDGothic-Regular.ttf | BIZ UDゴシック Regular | 1.05 | The BIZ UDGothic Project Authors | SIL Open Font License 1.1（[OFL.txt](OFL.txt)） | Debian/Ubuntu パッケージ `fonts-morisawa-bizud-gothic` 1.05-2（上流：github.com/googlefonts/morisawa-biz-ud-gothic） |

- 用途：台帳PDFの日本語表示。PDFには使った文字だけを抜き出して埋め込む（端末のフォントに依存しない）。
- フォントファイル自体は改変せず、アプリに組み込んで配布する。OFL 1.1 は、ライセンス文の同梱を条件に、単体での販売以外の再配布・組込みを認めている。
- OFLの規定により、このフォントで作成したPDF（文書）にはOFLの条件は及ばない。
- アプリの「このアプリについて」等でライセンス文を表示できるよう、OFL.txt を同梱する。
- 収録範囲：JIS X 0208（第1・第2水準）6,879字すべて、Windows機種依存文字（①・㈱・髙・﨑等）。収録外の文字（BMP外の漢字・絵文字・外字）はPDFで「〓」になり、出力時に警告する。
