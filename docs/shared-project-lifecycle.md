# 共有工事の編集・終了・ごみ箱

`202607270001_shared_project_lifecycle.sql` は、既存の共有工事を初期化せず、すべて `active` として扱います。

## 状態

- `active`: 参加・写真送信・台帳編集が可能
- `closed`: 既存データは閲覧可能。新規参加と書込みは不可
- `trashed`: 通常一覧から非表示。管理者だけが復元または空工事の削除を検討

## 管理操作

管理者は、revisionを指定するRPCだけで工事情報と状態を変更します。

- `update_site`
- `rotate_site_join_code`
- `close_site`
- `reopen_site`
- `trash_site`
- `restore_site`
- `delete_empty_site`

参加コードや会社の管理コードは監査ログへ記録しません。工事名・工事IDの更新、終了、再開、ごみ箱、復元、空工事削除は操作種別だけを監査ログへ記録します。

## 空工事の完全削除

`delete_empty_site` は、作成者本人である管理者が、ごみ箱内の工事名を正確に確認した場合だけ実行できます。写真、保存先情報、台帳、工事マスター、同期イベント、Storageオブジェクト、作成者以外の所属が1件でもある場合は、トランザクション全体を中止します。削除実行記録はサイト行と共に消えない専用監査表へ残します。写真がある工事の完全削除機能は提供しません。

## 適用

本migrationは `202607220001_site_creation_code.sql` の後に1回だけ適用します。再実行はpreflightで停止します。本番適用前に、空の検証環境で基盤migrationから順に適用し、`202607270002_lifecycle_verification.sql`を実行してください。
