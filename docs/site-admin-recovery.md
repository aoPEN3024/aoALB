# 現場管理コードと端末復旧

この機能は、メールアドレスや個人アカウントを使わず、工事ごとの
「現場管理コード」で別端末を管理者として登録するための基盤です。

## 3種類のコード

- 会社共通の現場作成コード：新しい共有工事を作れるか確認します。
- 工事ごとの参加コード：メンバーとして参加します。管理者にはなれません。
- 工事ごとの現場管理コード：別端末を管理者として登録します。

現場管理コードは`private.site_admin_codes.code_hash`へbcryptハッシュだけを
保存します。平文用の列、ログ、監査情報はありません。

## 既存工事

migrationは既存工事へコードを自動設定しません。既存adminは従来どおり
管理でき、管理画面から初回コードを設定できます。設定前は
`claim_site_admin`が外部向けの共通エラーを返します。

## 停止端末の復旧

通常の参加コードでは停止端末を復帰できません。正しい現場管理コードは、
端末交換・ブラウザデータ消失時の復旧要素であるため、停止済みの同一匿名
ユーザーも再びadminとして有効化できます。コード漏えいが疑われる場合は、
有効なadminが現場管理コードを変更すると旧コードは直ちに無効になります。

## 適用順

1. `supabase/migrations/202607290001_site_admin_recovery.sql`
2. `supabase/verification/202607290002_site_admin_recovery_verification.sql`
3. aoPIC・aoALBの対応UI

rollback SQLは、管理コードの設定・利用履歴が1件でもある場合は停止します。
未使用環境に限り、元の作成者固定`delete_empty_site`を復元して追加オブジェクトを
削除できます。実行には対象環境の確認と明示許可が必要です。
